# みかんから出るニャ！

[公開ゲーム](https://haruandren-commits.github.io/mikan-neko-game/)

9個のみかんから出てくるオリジナルの白猫をタップして押し戻す、iPhone向け縦画面ブラウザゲームです。30秒経過、または3匹が完全に脱出すると終了。3コンボごとに得点が増え、10秒ごとに脱出までの猶予が短くなります。空振りに減点はありません。

## グラフィックとアニメーション

猫・みかんは外部素材を使わないオリジナルのインラインSVGです。丸顔の白猫、短い手足、鈴付き首輪、両手、耳、尻尾を独立したパーツで描画しています。

- 待機：上下の輪郭がつながった光沢のみかん
- 準備（300ms）：小刻みな震え、横の割れ目、のぞく目
- 登場：下の皮が残り、両手で上の皮を持ち上げながら全身を伸ばす
- 脱出中：まばたき、耳・尻尾・上の皮の小さな揺れ
- 成功：驚き顔、引っ込み、皮の閉鎖、バウンド、星と得点・コンボ表示。3コンボ以上では表情を強調
- 逃走（650ms）：上の皮を放り投げ、専用の画面レイヤーで画面外へジャンプ。脱出完了時にライフを1つ減らし、みかんを復元

準備中のタップは無効です。立ち上がり開始後は猫の顔・胴体・上の皮を含むマス全体が判定対象です。成功・逃走が確定した猫への連打で得点は増えません。

音は右上のボタンでONにできます。効果音はWeb Audioで合成し、成功・逃走開始・終了に同期します。別アプリやタブへの移動でタイマーとゲーム中の全アニメーションを自動停止し、「つづける」で再開します。最高スコアはブラウザに保存します（保存不可でも遊べます）。

## ファイルと開発

- `index.html`：画面とダイアログ
- `game.css`：スマホレイアウトとSVGアニメーション
- `game.js`：オリジナルSVG、状態管理、タップ、音、タイマー
- `originals/mikan_neko_game.html`：最初に添付されたHTMLを変更せず保存

ビルド、外部ライブラリ、APIキーは不要です。公開時は **index.html・game.css・game.jsを同じ階層に** 配置してください。画像・フォント・音源の外部通信はありません。

```sh
cd /workspace/mikan-neko-game
python3 -m http.server 8000 --bind 0.0.0.0
```

PCではブラウザで `http://localhost:8000` を開きます。停止は Ctrl+C。

## 自動テスト

Playwrightと対応ブラウザが必要です。サーバー起動後：

```sh
TEST_BROWSERS=chromium CHROMIUM_PATH=/usr/bin/chromium node tests/smoke.cjs
CHROMIUM_PATH=/usr/bin/chromium node tests/reactions.cjs
CHROMIUM_PATH=/usr/bin/chromium node tests/animation.cjs
```

別のサーバーを使う場合は `BASE_URL=http://127.0.0.1:8003` のように指定します。ブラウザを自動取得済みの環境では `CHROMIUM_PATH` を省略できます。`smoke.cjs` は既定でChromiumとWebKitの両方を対象にします。

- `smoke.cjs`：9個のSVG、準備・立ち上がり・待機、ランダム出現、得点・コンボ、連打、一時停止、逃走中タップ無効、脱出完了後のライフ減少と復元、終了・再挑戦、30秒終了、3段階の難易度、音切替、アプリ切替、画面幅320/375/390/430px
- `reactions.cjs`：上の皮・顔・胴体への実タッチイベント、表情とコンボ、アニメーション時間の停止、逃走後コンボリセット、動きを減らす設定
- `animation.cjs`：上下の皮の接続、割れ目の目、途中の立ち上がりと持ち上げ位置、成功時の表示と閉鎖、各画面幅でのスクリーンショット

60fpsを目標に主にtransformとopacityをアニメーションし、非アクティブな8マスでは常時アニメーションを動かしません。カウント表示は値が変わった時だけ更新します。実機iPhoneでのフレームレートは未測定です。

今回のSVG改良版の実機iPhone Safariテストは未実施です。WebKitは公式配信元が403を返し、権限付き再試行でも取得できませんでした。公開後の実機では音、連打、ホーム画面への移動・再開、30秒終了、再挑戦を確認してください。

## iPhoneからのGitHub Pages設定

既存のPages設定は `main` / `/ (root)` のままで利用できます。`main` へ変更が入ると自動で再公開されます。

新しく設定する場合：

1. Safariでリポジトリの **Settings** を開く。
2. **Pages** → **Build and deployment** を開く。
3. **Source** を **Deploy from a branch** にする。
4. **Branch** は **main**、フォルダーは **/ (root)** にして **Save** を押す。
5. デプロイ完了後、**Visit site** からゲームを開く。

公開先：`https://haruandren-commits.github.io/mikan-neko-game/`

Gitの履歴に旧版が残るため、以前の実装を確認・復元できます。既存アニメのキャラクター・画像・音楽は使用していません。
